Requires Windows 11 and Python 3.12 (64-bit)



YOU NEED TO INSTALL ***Forever Fishing*** ADDON AND RUN IT IN GAME BEFORE YOU CAN RUN THIS BOT: [Download here](https://www.curseforge.com/wow/addons/forever-fishing)



You need to be in fishing spot in game, anywhere, like you regularly would be.



1\. Extract all files from the ZIP

2\. Run INSTALL.bat once and wait for it to finish

3\. Run START.bat

4\. Cast manually in WoW, then press F8



F8: Start / pause

F9: Quit
