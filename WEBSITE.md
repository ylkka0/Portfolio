# Portfolio-verkkosivusto

Tämä React + Vite + TypeScript -sivusto on lisätty olemassa olevan portfoliosisällön rinnalle.

## Paikallinen kehitys

```bash
npm install
npm run dev
```

Avaa terminaalin ilmoittama paikallinen osoite.

## Tuotantoversio

```bash
npm run build
npm run preview
```

Viten build-tiedostot tallentuvat `dist/`-hakemistoon.

## Julkaiseminen

Sivusto sopii esimerkiksi Verceliin (Framework Preset: Vite; Build Command: `npm run build`; Output Directory: `dist`).

GitHub Pages -julkaisua varten `vite.config.ts` käyttää suhteellista base-polun asetusta `./`; GitHub Pages tarvitsee silti erillisen julkaisuasetuksen tai työnkulun.

## Sisällön täydentäminen ennen julkaisua

- Vahvista haluttu julkinen nimi, esittelyteksti ja yhteystapa.
- Lisää oikeat projektikuvat käyttäen vain aineistoa, jonka saa julkaista.
- Masadeskissa näytetään anonyymi esimerkkitulos; älä julkaise Freshdesk-asiakkaiden henkilö- tai tukitietoja.
- Tarkista projektien ja teknologioiden tarkat roolit sekä toimivat ulkoiset linkit.

Alkuperäiset Markdown-projektikuvaukset on säilytetty ennallaan.
